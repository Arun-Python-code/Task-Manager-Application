# Task Manager Application

A full-stack Task Manager application built with React, Django REST Framework, and MySQL. The application provides user authentication, task creation, updating, deletion, task assignment, status and priority tracking, filtering, and a responsive dashboard.

## Tech Stack

- Frontend: React, JavaScript, HTML, CSS, Bootstrap
- Backend: Python, Django, Django REST Framework
- Database: MySQL
- API Testing: Postman
- Version Control: Git, GitHub
- CI: GitHub Actions

## Features

- User authentication
- Create, update, and delete tasks
- Assign tasks to users
- Track task status and priority
- Filter tasks
- Dashboard with task statistics
- RESTful APIs
- Responsive user interface
- Automated backend testing and frontend build using GitHub Actions
